## WordPress recovery and clearer site operations

- WordPress Debug can enable a managed debug configuration while keeping error
  display off for visitors. Output goes to a private per-site log; the panel
  reads only the newest 256 KiB and can clear the log without exposing its host
  path to the browser.
- WordPress Search and replace requires an active recovery target and a fresh
  dry-run preview. The one-use, 15-minute preview is bound to the user, site,
  recovery target and exact values. Apply creates a recovery snapshot before
  changing the database. A possibly partial failure stops blind replay and
  names the snapshot that an operator must restore before trying again.
  Redis invalidation is site-scoped; existing FastCGI page caches can retain
  previous content for up to their ten-minute TTL.
- Backup pages now show up to 50 recent scheduled and manual runs with their
  source, timing, result and current restore-point availability. Retention can
  remove a restore point without changing the recorded successful run.
- Request logs now support exact IP, HTTP status or status-family, method and
  path filters. The same filtered, bounded result can be copied in the browser
  or downloaded as CSV; spreadsheet-leading formula characters are neutralized.
- Sign-in names can be usernames or email addresses. Users can rename their own
  sign-in after confirming their current password, and authorized administrators
  can rename managed users without changing identity, role or site grants.
- The site sidebar has a clearer site identity, icons and nested WordPress tools.
  Embedded CSS and JavaScript use content-derived URLs and validators so Firefox
  does not keep a mismatched asset across executable upgrades or navigation.
- WordPress plugin inventory and deactivation run without loading ordinary
  plugins or the active theme. A plugin that breaks normal WordPress bootstrap
  can therefore remain visible and can be deactivated; malformed inventory
  output is still reported as an error instead of being guessed.

The interface includes translated catalog entries for the new concise controls
in all supported locales, with explicit English fallback for unmarked or missing
copy. This is not a claim that every page or runtime error is fully translated.
