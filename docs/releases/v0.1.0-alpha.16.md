## File manager corrections

Fix file search and nested-folder listings when the broker runs outside a site's
public directory. Directory-entry metadata now comes from the open directory
handle, preserving symlink confinement and correctly identifying nested files.

The contextual actions menu also remains visible in folders containing only one
file. On narrow screens, primary controls wrap below the directory path.

This corrects problems caught during the alpha.13 VPS deployment checks. All
alpha.13 features and the compact contextual file toolbar are included.

Regression tests cover an unrelated working directory, nested listings, symlink
exclusion, and recursive operations. The corrected read-only listing/search code
was also exercised against the existing VPS site before publication.

Upgrade through the normal installer. The upgrade retains its local recovery
snapshot and preserves site data, identities, credentials and configuration.

The unpublished alpha.14 and alpha.15 builds were superseded by this release so
the traversal and responsive-layout corrections ship together.
