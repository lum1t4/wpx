## A more consistent panel

- Light, dark and system appearance, with language and appearance preferences in
  Account settings. The account menu uses a compact icon control.
- Redesigned notifications, WordPress fleet and scheduled tasks. Cron creation
  includes presets and a custom expression; fleet updates use inline selection
  and a contextual action bar.
- Request logs filter by IP address, HTTP status or family, HTTP method and path.
  Errors is a filter preset. Filters apply to the bounded recent request window.
- Updated WordPress, storage and file-refresh icons, while retaining the existing
  monitoring icon and text-only site navigation.
- Email, Slack webhook and Telegram alert delivery with separate channel controls
  and test actions. Credentials are encrypted and omitted from rendered pages.
- Fail2ban and nftables are default dependencies on new installs and upgrades.
  Dependency checks run before WPX is stopped. Existing firewall rules are
  preserved; WPX does not enable the host's nftables ruleset loader.

All alpha.16 file-manager corrections and previous hosting features are included.
Use the normal installer to upgrade; it retains a local recovery snapshot.

Slack and Telegram require operator-supplied credentials. Provider contracts and
failure handling have automated coverage; live provider delivery requires the
channel's Test action after configuration.
