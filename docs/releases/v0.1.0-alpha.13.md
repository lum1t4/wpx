## Site operations and interface improvements

The file manager now keeps Upload and New folder in a compact directory header.
Selection-specific actions appear only when useful, with less common operations
in an overflow menu. Database pages use consistent panel styling, site pages
have dedicated navigation, and short operations refresh after confirmed success.

This release adds:

- Resumable chunked uploads, streamed downloads, multi-select, copy/move,
  rename/delete, archive/extract, and cross-directory file search.
- WordPress fleet inventory and batch plugin updates through recovery backups.
- Per-site scheduled commands and WordPress cron replacement, including an
  active-scheduler check before disabling WordPress's own runner.
- Basic authentication and Cloudflare-only origin access.
- Opt-in WordPress request limits, fail2ban/nftables progressive bans and
  suspicious-access analysis.
- SMTP operator alerts, service/resource diagnostics, OOM reporting and
  optional managed swap.
- Node.js 24 runtime management, TLS-required ProFTPD accounts and local
  outbound Postfix.
- 33 language catalogs for common interface labels and bounded cloud IP
  discovery for AWS, DigitalOcean, GCE, Hetzner and Vultr.

## Upgrade and boundaries

The existing installer upgrades alpha.12 in place and retains a local recovery
snapshot. Let active jobs finish before upgrading. Existing site content,
identities, credentials and access configuration are preserved. New controls
remain opt-in; upgrading does not install optional hosting services or enable
firewall bans. Fresh installations now include cron and fail2ban. On existing
servers, cron.service must be installed and active to enable schedules;
WordPress defenses provide an administrator-only dependency installation action.

Node services currently permit loopback networking only, including outbound
connections. Mail is local outbound submission, not mailbox hosting. The current
origin-IP defenses cannot be combined with Cloudflare-only mode because that
would group or ban shared Cloudflare edge addresses. File operations have
bounded size/traversal limits. Longer UI copy and backend errors can remain in
English.
